## Project Overview

In this project, **a Fast-R-CNN and R-CNN (Region-based Convolutional Neural Network)** was implemented for object detection using region proposals generated by **Selective Search**. The objective was to detect two types of objects—**Bus** and **Truck**—and predict their corresponding bounding boxes.

For each proposed region generated by Selective Search, the ground-truth bounding box having the highest **Intersection over Union (IoU)** with that region was selected as its target bounding box. The class label associated with this ground-truth bounding box was then assigned as the target class label for the proposed region.

### Bounding-Box Regression

Instead of directly predicting the target bounding-box coordinates, the difference between each proposed region and its corresponding target bounding box was calculated as a **delta**.

The Fast-R-CNN and R-CNN model predicts a four-dimensional delta for each proposed region. During training, these predicted deltas are compared with the corresponding ground-truth deltas in the loss function.

### Model Architecture

**VGG16** was used as the feature-extraction backbone. The extracted features were then passed into two separate networks:

* **Classification network:** predicts whether the proposed region corresponds to a Bus, Truck, or Background.
* **Bounding-box regression network:** predicts the four coordinates of the bounding-box delta.

### Inference

During testing, ground-truth bounding boxes and IoU comparisons are not available. Therefore, all valid region proposals generated by Selective Search for a given image are passed through the trained Fast-R-CNN and R-CNN model.

The predicted bounding-box deltas are then applied to their corresponding region proposals to obtain the predicted bounding boxes.

The resulting detections are subsequently filtered using:

1. **Background filtering** — predictions classified as Background are removed.
2. **Confidence thresholding** — predictions below the specified confidence threshold are removed.
3. **Non-Maximum Suppression (NMS)** — highly overlapping detections are suppressed to reduce duplicate predictions.

The remaining bounding boxes and their predicted class labels constitute the final detections.

### Dataset and Data Split

The dataset contains a total of **500 images**, consisting of Bus and Truck images.

The dataset was divided into:

* **Training set:** 450 images
* **Validation set:** 25 images
* **Test set:** 25 images

During training, the model with the **lowest validation loss** was retained as the best-performing model.

A **dropout rate of 0.3** was also incorporated into the model to help improve generalization to unseen images.
